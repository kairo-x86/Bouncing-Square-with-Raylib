# Bouncing-Square-with-Raylib
I wanted to do something with graphics, so I decided to use raylib to make a small program.

I made build.bash because doing the same two commands every time i wanted to test it got annoying. You can add clear on the next line after LD_LIBRARY_PATH=~/raylib/lib ./main to not have to see the massive wall of text it prints, but you won't be able to see errors.
Didn't learn much besides how to draw with raylib.
